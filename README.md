# أيقونات 3D واقعية لبوستات باقات بوت مواعيد العيادات

تصميم وتطوير: **المهندس إبراهيم فهيم**

المستودع ده بيرسم أيقونة واقعية لكل نوع تحليل (سكر، كلى، كبد، غدة درقية...) بنفس ستايل فولدر B،
والبوت بيستخدمها في بوست الباقة.

## التشغيل

- **Actions ← Generate icons ← Run workflow**، وبعد كام دقيقة الصور بتبقى في فولدر `icons/` و`preview.jpg`.
- عايز صورة معينة تتعاد بشكل تاني؟ اكتب اسمها في **only** وغيّر رقم **seed**.
- عايز تضيف تحليل جديد؟ ضيف سطر في `subjects.json` (`"الاسم": "وصف بالإنجليزي"`)، والرسم بيشتغل لوحده.

## مصدر الرسم

- **من غير أي مفتاح:** Pollinations (موديل Flux) مجاني.
- **أحسن جودة (اختياري):** اعمل مفتاح مجاني من https://aistudio.google.com/apikey
  وحطه في **Settings ← Secrets and variables ← Actions** باسم `GEMINI_API_KEY`.

## في البوت

حط صور `icons/*.jpg` في فولدر `icons` جوه فولدر بيانات البوت، وهي بتتستخدم في البوست لوحدها.
